# Portfolio

Mon portfolio de compétences en maintenance et support informatique : matériel, systèmes, données, imprimantes, mobiles et relation client.

Le site tient dans un seul fichier, `index.html`. Il est publié avec GitHub Pages.

Pour changer le nom, l'email ou les liens, modifie le bloc `PROFIL` au début du `<script>` dans `index.html`.
